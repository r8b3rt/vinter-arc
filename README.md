# Lumber Run · Побег из леса

Русскоязычный бесконечный раннер на Phaser 3 и TypeScript. Беги по лесу, собирай золотые жёлуди и открывай облики. Стрелки или WASD меняют дорожку, запускают прыжок и подкат. Пробел тоже отвечает за прыжок, Esc ставит забег на паузу. На сенсорном экране используй свайпы.

## Локальный запуск

Понадобится Node.js 22 или новее. В корне репозитория выполни команды по порядку.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite. Для проверки готовой сборки выполни `npm run build`, затем `npm run preview`.

## Публикация

В Settings → Pages → Build and deployment выбери GitHub Actions. Отправь изменения в main или открой Actions → Lumber Run Pages → Run workflow. После тестов и сборки задание deploy-pages выдаст адрес игры. Базовый путь относительный, зависимости включены в сборку. Для этого публичного репозитория предусмотрен адрес https://r8b3rt.github.io/vinter-arc/.

Рекорды, настройки и покупки хранятся в браузере. Описание правил и проверок находится в docs/.
