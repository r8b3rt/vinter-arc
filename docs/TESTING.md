# Проверки

npm test запускает пять модульных сценариев. Они проверяют 10 000 процедурных рядов, реакции на столкновения, движения, усиления, повреждённые сохранения и покупку облика.

npm run build проверяет типы и собирает production-версию. После сборки npx playwright test запускает Chromium на двух размерах экрана. Сценарии проверяют обучение, клавиатуру, жесты указателя, настройки, паузу, перезапуск, сохранение статистики и ошибки консоли.

Локально прошли пять модульных и два браузерных сценария. Просмотрен скриншот меню настольной версии. Мобильная проверка использует эмуляцию размера экрана и события указателя. Проверки на физических устройствах и профилирование FPS остаются в ROADMAP.md.
