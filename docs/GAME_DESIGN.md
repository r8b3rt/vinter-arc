# Правила лесной тропы

Каждый ряд оставляет свободную дорожку с желудями. Интервал между рядами учитывает скорость и время двух перестроений. За метр начисляется очко, за жёлудь ещё десять. Усилитель ×2 удваивает начисление.

Камни, пни, брёвна, ямы, грязь и изгороди можно перепрыгнуть. Ветки и арки требуют подката или обхода. Валун, костёр и берлога завершают забег при прямом столкновении. Куст заставляет споткнуться. После лёгкой ошибки действует короткая защита, а медведь постепенно отстаёт.

Магнит собирает жёлуди на соседних дорожках. Щит поглощает один удар, ускорение даёт временную защиту, приманка отбрасывает медведя. Через каждые 500 метров меняется окружение. Все шесть обликов используют одну физическую модель.
