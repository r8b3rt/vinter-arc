# Работа с проектом

Используй Node.js 22+. Перед коммитом запусти npm test, npm run build и npx playwright test. Для первого запуска браузерных тестов установи Chromium командой npx playwright install chromium --only-shell. Меняй баланс в src/model.ts. При изменении схемы сохранений добавь миграцию и тест чтения старых данных. Сохраняй русские подписи и управление свайпами.
